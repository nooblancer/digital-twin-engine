# Frontend - Digital Twin Dashboard

React dashboard for visualizing the Digital Twin Engine in real time.

## Planned Features

- Live sensor data charts (updating in real-time)
- **Data source switcher** — dropdown to select between all 11 supported data sources
- Engine/sensor health status indicators
- Anomaly alert feed
- Predicted vs. actual state overlay
- Historical trend explorer with time-range selection
- Pipeline health monitoring

## Tech Stack (Planned)

- React 18 / Next.js
- Recharts or D3.js for visualizations
- WebSocket connection for live updates
- TailwindCSS for styling
